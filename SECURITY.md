# Security policy

Güvenlik açığı olabileceğini düşündüğünüz bir durumu herkese açık issue olarak
paylaşmadan önce GitHub deposundaki **Security → Report a vulnerability**
akışını kullanın.

Raporunuza etkilenen sürümü, yeniden üretme adımlarını, beklenen/gerçek sonucu
ve varsa günlükleri ekleyin. Parola, erişim anahtarı veya kişisel trafik
içeriği paylaşmayın.

Yalnızca güncel yayın desteklenir. Kurulum dosyalarını resmi GitHub Releases
sayfasından indirin ve yayın notlarındaki SHA-256 değerleriyle karşılaştırın.
